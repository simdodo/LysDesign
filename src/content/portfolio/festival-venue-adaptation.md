Festival adaptation is usually a priority exercise. There is rarely enough time to rebuild the full idea, so the useful question is what must be protected: the artist silhouette, the main cue hits, the colour language, the audience moments or the busking structure.

The strongest versions are built around fixture roles, not exact fixture names. If the rig changes, the file still has a way to choose front light, backlight, beams, audience hits or specials without rewriting everything. Daylight and short changeovers make this even more important because decisions need to be made while the clock is moving.
